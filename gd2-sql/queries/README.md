# queries/

Bài tập truy vấn, mỗi chủ đề một file.

## Quy ước

- Tên file: `<số>_<chủ-đề>.sql`, ví dụ `01_join_basic.sql`, `05_window_function.sql`.
- Mỗi câu truy vấn có comment phía trên gồm:
  1. **Đề bài** — cần lấy gì;
  2. **Dự đoán** — mình nghĩ sẽ ra bao nhiêu dòng / kết quả gì (ghi TRƯỚC khi chạy);
  3. **Kết quả thật** và lý do nếu khác dự đoán.
- Với câu có nhiều cách viết (JOIN vs subquery vs EXISTS), giữ cả các cách và ghi so sánh.
